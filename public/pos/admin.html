Sales report Export to the Sales-Report folder · import it back anytime

How it works
  • Export: leave the dates empty for every finished order, or pick a range. The file is saved into the Sales-Report folder (inside pos-admin-portal) and opens in Excel with one row per item sold. With Remove exported orders from sales ticked, those orders are erased from the admin sales once the file is safely saved. Orders still in progress are never exported or removed.
  • Excel tips: filter the Status column to hide Cancelled orders before adding up sales. Order Total is filled only on the first row of each order, so a SUM never counts an order twice.
  • Import: pick a file from the list. It only shows files in the Sales-Report folder, so copy an edited file (saved in Excel as CSV UTF-8) into that folder first. Importing brings the orders (and their sales) back. Orders already in the system are skipped, so importing twice never doubles your sales. Stock is not changed.
